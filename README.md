# E-Commerce Customer Segmentation

## Objective
This project groups e-commerce customers according to their purchasing behaviour and presents the distribution of the resulting groups.

## Tools
- Python
- Pandas
- Matplotlib

## Method
Customer-related values are organised in a Pandas DataFrame and grouped into categories based on the structure of the data. Matplotlib is used to present the group distribution in a donut chart.

## Result
The project produces a visual summary of customer categories, including casual window shoppers, loyal repeat buyers, and VIP high spenders.
