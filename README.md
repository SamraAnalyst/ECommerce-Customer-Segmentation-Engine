# E-Commerce Customer Segmentation & Unsupervised Clustering Engine

This project demonstrates an unsupervised machine learning categorization model designed to segment corporate e-commerce client groups based on buying behaviors.
![Customer Clusters Donut Chart](Output%20(8).png)

### Analytical Operations:
* Modeled distinct customer arrays into structured Pandas data panel variables.
* Visualized structural cluster counts distributions using a custom edge-bounded Donut Pie Chart framework via Matplotlib.
